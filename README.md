# YouTube Data Analysis – Exploratory Data Analysis (EDA)

## 📌 Project Overview
This project focuses on performing exploratory data analysis (EDA) on a global YouTube dataset to understand subscriber growth patterns, channel performance, and content trends across different categories, countries, channel types, and time periods.

The analysis demonstrates the complete data analysis workflow, including data loading, cleaning, aggregation, visualization, and interpretation using Python.

---

## 🎯 Objectives
- Analyze subscriber distribution across YouTube categories and channel types
- Understand country-wise contribution to subscriber counts
- Study time-based trends using channel creation year and month
- Evaluate recent subscriber growth (last 30 days)
- Visualize insights using clear and interpretable plots

---

## 🛠 Tools & Technologies
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📊 Analysis Performed
- Mean and median subscriber analysis by category and channel type
- Country-wise and category-wise subscriber distribution using stacked bar charts
- Upload activity analysis across channel types
- Time-series analysis using created year and created month
- Recent subscriber growth analysis (last 30 days)
- Data visualization using bar charts and line plots

---

## 📈 Visualizations
The project includes:
- Bar charts for category and channel type comparisons
- Stacked bar charts for country-wise subscriber distribution
- Line plots for time-based trends
